# ServerPinner

Pin servers to the top of your server list.

Right-click a server and choose **Pin server to top**. Pinned servers appear above your server list, in the order you pinned them, and stay where they are in your folders. Choose **Unpin server** to remove one.

Pins are stored in Endcord's settings, so they follow you through settings sync and backups. Discord's own server order is never changed.
